# Sentinel Lab design system

The initial desktop and mobile concepts were generated and inspected during the design pass. The visual contract below is the durable implementation reference.

## Visual contract

- Background: graphite black (`#090c0d`)
- Open surface: coal (`#0d1112`)
- Primary text: mineral ivory (`#ece3d7`)
- Muted text: stone (`#a8a097`)
- Rule: cool graphite (`#363a3b`)
- Trace: mineral teal (`#49b99f`)
- Warning and event: safety amber (`#f3a51b`)
- Threshold: mineral red (`#db684c`)
- Secondary trace: faded violet (`#aa96c6`)
- Headline: high-contrast editorial serif
- UI chrome: deliberate monospace stack, 12–15px desktop and 13–16px mobile
- Containers: open rails and hairline rules; no bento grid, glass, glow, or ornamental gradients
- Motion: trace redraw and one running-status pulse; respect reduced motion

## Component families

- Quiet application header and responsive menu
- Run configuration rail
- Interactive SVG causal trace
- Single evidence ledger / mobile evidence drawer
- Proof-gate ledger
- Artifact import surface
- Baseline comparison table
