KNOW YOUR BOUNDARY

A useful window.
A visible boundary.

What you can connect

Public HTTP or HTTPS websites and public IP addresses you own or are authorized to monitor. Private addresses, localhost, credentials in URLs, and unsupported destinations are rejected by the collector.

What each check measures

A bounded public endpoint check: DNS answers and timing for hostnames, pinned TCP connection timing, TLS handshake and certificate metadata, HTTP response timings and selected response-header controls. Optional public redirect following and a page fingerprint inspect up to 64 KiB without retaining response content. Elapsed time includes the collector’s network path; it is not page-load time or origin processing time.

When it runs

At least 15 seconds between completed checks for each active target. Checks pause while this tab is hidden, and resume when visible. Closing the tab stops this foreground session. Reloaded records never reconnect automatically. Pausing cancels the local request and stops future checks; a request already sent may still complete at the collector.

What endpoint checks leave invisible

Visitor traffic, security events, device activity, internal networks, packet contents, authentication outcomes and application logs are outside the public endpoint collector. Sensor sources below can supply the flow, DNS, TLS and event metadata their own captures contain. The observatory does not start packet collection.

Brain / Sentinel limits

Experimental numerical change signals describe this sequence of measurements. They are not attack probabilities, security verdicts, or proof of protection. Forecasts estimate the next measured latency and are compared with persistence; useful predictive skill is not presumed.

Records & privacy

Up to 2,048 target observations and 64 versioned target baselines are retained server-side within a seven-day window, with older rows purged on collection. The most recent 128 records per target can be restored. Up to 500 observations are also retained in this browser tab’s session storage when available. Targets and records may be restored as paused after a reload. Export creates an evidence JSON file; review it before sharing. Sensor sources retain up to 2,000 accepted records in this tab’s memory; use their evidence export before closing the tab. No credentials or request bodies should be entered.

Interpretation is manual. Configured Sol calls use the OpenAI API within the server’s daily budget and cooldown. Missing configuration leaves deterministic evidence notes available; no browser model download runs.
