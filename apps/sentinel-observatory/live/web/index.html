KNOW YOUR BOUNDARY

A useful window.
A visible boundary.

What you can connect

Public HTTP or HTTPS websites and public IP addresses you own or are authorized to monitor. Private addresses, localhost, credentials in URLs, and unsupported destinations are rejected by the collector.

What each check measures

A bounded HTTP HEAD request from the hosted collector, its status, elapsed time, selected response-header controls, and collection errors. Elapsed time includes the collector’s network path; it is not page-load time or origin processing time.

When it runs

At least 15 seconds between completed checks for each active target. Checks pause while this tab is hidden, and resume when visible. Closing the tab stops this foreground session. Reloaded records never reconnect automatically. Pausing cancels the local request and stops future checks; a request already sent may still complete at the collector.

What remains invisible

Visitor traffic, Cloudflare security events, device activity, internal networks, packet contents, authentication outcomes, application logs, and availability from other vantage points.

Brain / Sentinel limits

Experimental numerical change signals describe this sequence of measurements. They are not attack probabilities, security verdicts, or proof of protection. Forecasts estimate the next measured latency and are compared with persistence; useful predictive skill is not presumed.

Records & privacy

Up to 500 actual observations are retained in this browser tab’s session storage when available. Targets and records may be restored as paused after a reload. Export creates an evidence JSON file; review it before sharing. No credentials or request bodies should be entered.

No paid model calls, network-protection changes, or defensive actions are performed.
